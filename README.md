# IntroMLCapstone
- This project containes all the ML modle for my Capstone project.

Setup:

1.Clone or download the repo.

2.  Make sure the following are installed:

    - python 3.x

    - numpy

    - pandas

    - matplotlib

    - scikit-learn

    - xgboost (for the XGBoost notebook)

3. Place train.csv, I have provided it to you already.

4. Open a notebook (I used Google Colab).

5. Open Colab, upload the train.csv to the same root folder.

6. Run all the cells.
